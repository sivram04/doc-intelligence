Finance teams still retype invoices.

Every supplier lays out an invoice differently, and scans arrive tilted and blurred. Template-based tools break on each new layout, and chat-style AI can return a confident number that isn't on the page. So someone keys the figures into a spreadsheet and the ledger by hand.

  • No templatesA fine-tuned model reads the page, so a supplier's new layout needs no setup. It was tested on invoice designs it never saw in training.
  • Checks before trustLine items must add up to the subtotal, and tax plus subtotal must equal the total. Anything that fails goes to a person to check, with the page beside it.
  • Every number has a sourceEach value is linked to the exact place on the page it was read from, so a reviewer confirms it at a glance.

Cited report summaries

Upload a long PDF, such as a 70-page annual report or contract. You get a summary where every sentence links to its page, and you can ask questions.

  • Statements the document doesn't back up are left out
  • Says "not stated" instead of guessing

How it's built.

An end-to-end document pipeline, with the model as one checked step rather than the whole product.

Python · FastAPIPyMuPDF · Tesseract · RapidOCRQwen2.5-1.5B · QLoRAOllama Gemini APIBM25 + embeddingsSQLite / PostgresRedis · arqDockerPlaywright
  1. Read the page

    PDF text and layout come from PyMuPDF, and scans go through OCR. Each word keeps its position, which is what makes every value traceable.

  2. Extract the fields

    A Qwen2.5-1.5B model fine-tuned with QLoRA on a free Kaggle GPU, served on CPU by Ollama. Trained on thousands of synthetic invoices in varied layouts plus real receipts. The hosted demo uses Gemini instead.

  3. Check the numbers

    Validators test sums, tax, dates and currency. Confidence thresholds fitted on held-out data decide which fields a person must check.

  4. Review and learn

    A review queue shows the page with each field's source highlighted. Corrections are saved as training data for the next model.

  5. Post and export

    Balanced journal entries, tax split by type, and CSV exports, including quickbooks_journal.csv.

  6. Long documents

    Pages are indexed with BM25 and embeddings. A statement is kept only if its quote is found on the cited page.

Run it on your own machine

DocIntel is open source. Locally it uses the fine-tuned model through Ollama, so documents never leave your computer and it costs nothing per page. No GPU is needed.
